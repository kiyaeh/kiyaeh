# Requirements — GitHub Profile README Upgrade

## Overview
Upgrade Ewnetu Tesfaye's (kiyaeh) GitHub profile README from its current solid baseline to a significantly more advanced, visually impressive, and engaging presentation that stands out among developer profiles.

## Requirements

### R1 — Advanced Hero Section
The header must use a more visually rich banner with a higher-impact gradient, larger animated text, and a subtitle that communicates both identity and current focus clearly. The typing animation must include more descriptive lines with emoji for personality.

### R2 — Animated Activity Banner
Add a `github-readme-activity-graph` widget showing recent contribution activity with the tokyonight theme, styled to match the profile's teal/navy color palette.

### R3 — Enhanced "About Me" section
Replace the plain YAML block with a visually structured two-column table layout using emoji icons for each field, making it scannable and visually rich without losing the technical tone.

### R4 — "Currently Building" Spotlight
Add a dedicated, visually prominent spotlight section for Learnova using a capsule-render venom/soft_cc banner or styled HTML block — making the current main project immediately visible.

### R5 — Architecture Timeline (The Arc)
Keep the Mermaid diagram but enhance it with a richer flowchart showing more detail (tech stack per phase, status badges). Add a prose narrative below the diagram.

### R6 — Skill Badges with Proficiency Grouping
Replace the flat skillicons grid with a more structured layout that groups technologies into tiers (Expert / Proficient / Learning) using shields.io badges styled with the profile colors, alongside skillicons for visual appeal.

### R7 — Project Cards with Visual Hierarchy
Replace plain `<details>` project entries with richly styled HTML table-based project cards that show: project emoji+name, status badge (🟢 Active / 🧪 Experimental / ✅ Shipped), stack badges, and a one-line impact description.

### R8 — Advanced GitHub Stats Layout
Upgrade the stats section with a 2×2 grid layout including: readme-stats (custom tokyonight), top languages, streak stats, and a WakaTime or activity graph. Use consistent sizing and spacing.

### R9 — Contribution Snake (keep + enhance)
Keep the snake SVG but place it in a dedicated visually framed section with a header and description.

### R10 — "What I'm Exploring" Section
Add a section highlighting current learning focus areas using progress-bar style badges or visual indicators (e.g., shields.io custom badges for AI/ML, Spring Cloud depth, etc.).

### R11 — Collaboration & Contact Section
Upgrade the contact/collaboration section with a visually distinct styled HTML block using a capsule-render soft banner or divider, listing collaboration interests with styled badges and a clear CTA.

### R12 — Footer
Use a more elaborate footer with a motivational quote, the snake animation if not placed above, and a capsule-render footer matching the header's gradient direction.

### R13 — Color Consistency
All widgets, badges, and banners must use a consistent palette: primary `#2DD4BF` (teal), dark navy `#1e3c72`, mid teal `#0f9b8e`, dark green `#134e4a`. Background widgets use `tokyonight` theme.

### R14 — GitHub Markdown Compatibility
All HTML must be valid within GitHub's markdown renderer. No JavaScript, no CSS classes, no external font imports. Use only `align`, `width`, `height`, `src`, `href` attributes in HTML tags.
